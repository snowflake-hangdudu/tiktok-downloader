TikTok 视频下载助手 · 隐私政策

最后更新：2026 年 9 月 29 日 · 版本 1.0.0 · 常见问题

本扩展帮助用户在 TikTok 网页中识别并保存自己有权保存的公开内容。下载始终由用户主动发起。

本地数据

页面识别、下载队列、任务状态、文件名模板、主题、扫描结果和下载历史保存在浏览器本地扩展存储中。扩展不会将视频、账号信息、浏览记录、下载任务或历史记录上传给开发者。

下载文件由浏览器的下载功能保存到用户设置的下载目录。用户可以在扩展设置中清除历史、未完成任务或本扩展的全部本地数据。

联网请求

扩展读取 TikTok 当前页面中公开可访问的页面数据与资源地址，并由浏览器下载功能访问相应的 TikTok 媒体资源。扩展也会向配置服务请求公告、合作说明和商店评分开关；该请求不包含视频、账号或下载历史。

访问边界

扩展不绕过私密视频权限、登录或地区限制、付费限制、DRM 或其他访问控制，也不保证取得 TikTok 未向当前用户提供的资源版本。

权限用途

  • 页面脚本：读取 TikTok 页面当前公开显示的信息，并提供下载面板。
  • downloads：通过浏览器下载 API 保存用户选择的资源，并同步任务进度。
  • storage：本地保存设置、任务、创作者扫描结果与下载历史。
  • TikTok 媒体域名：下载页面公开提供的媒体资源。
  • 配置服务：读取公告、合作说明与商店评分开关。
